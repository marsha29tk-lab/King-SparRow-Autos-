# King SparRow AUTOS — GitHub Pages Ready

## Files
- `index.html` — homepage
- `catalog.html` — available cars catalog with price, make, model, year, condition and mileage
- `catalog.js` — catalog data, search, filters and reset button
- `404.html` — redirects invalid links to the car catalog
- `.nojekyll` — GitHub Pages compatibility
- `assets/logo.png` — King SparRow AUTOS logo

## Deploy to GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. Go to Settings → Pages.
4. Choose Deploy from a branch.
5. Select `main` and `/(root)`, then Save.

Edit vehicle information in `catalog.js` whenever new cars arrive or cars are sold.
